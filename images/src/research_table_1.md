| Layer                       | Recommendation                                                                                                                           | Why                                                                                                                                             | Fallback / alternative                                                                      |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| Language / style            | Plain Python scripts + one results notebook                                                                                              | Easier to explain and debug than LangChain/LlamaIndex abstractions; graders want to see *your* logic                                            | LlamaIndex if you want speed over transparency                                              |
| PDF parsing                 | **PyMuPDF** (text + block coordinates) + **pdfplumber** (tables); **Docling** for the hardest PDFs                                       | PyMuPDF is fast and gives you x/y positions → easy header/footer and column handling; Docling has the best layout/table models among open tools | `ocrmypdf` (Tesseract) for any scanned PDF                                                  |
| HTML pages                  | `trafilatura` or `BeautifulSoup`                                                                                                         | Removes navigation boilerplate from RBI/NPCI web pages                                                                                          | —                                                                                           |
| Chunking A                  | Fixed size: **512 tokens, 64–100 token overlap**                                                                                         | Standard baseline                                                                                                                               | 400/50                                                                                      |
| Chunking B                  | **Structure-aware**: split on RBI numbering (Chapter → paragraph `5.` → sub-para `5.1` / `(a)`), merge tiny sections, cap at ~800 tokens | Regulations are written as numbered clauses, so one clause = one answerable unit                                                                | Docling's hierarchical chunker                                                              |
| Dense embeddings            | **BGE-M3** (MIT, 1024-d, 8k context, runs on CPU)                                                                                        | Strong multilingual model (RBI/Gazette PDFs contain Hindi); also outputs sparse vectors                                                         | Qwen3-Embedding-0.6B (newer, stronger on MTEB)                                              |
| Vector index                | **Qdrant (local/in-process mode)** or FAISS                                                                                              | Qdrant has payload filters (`status = current`, `date <= X`) that you need for the superseded-circular part                                     | ChromaDB, LanceDB                                                                           |
| Keyword search              | **BM25** via `bm25s` (or `rank_bm25`)                                                                                                    | Exact terms matter a lot here: "KFS", "APR", "PA-P", "₹15,000", circular numbers                                                                | BGE-M3 sparse output                                                                        |
| Fusion                      | **Reciprocal Rank Fusion (RRF), k = 60**                                                                                                 | No score normalisation needed; the usual default                                                                                                | Weighted fusion + grid search                                                               |
| Reranker (only if it helps) | **bge-reranker-v2-m3** on the top 20–30 fused results                                                                                    | Cheap cross-encoder that runs on CPU                                                                                                            | Qwen3-Reranker-0.6B/4B (stronger, slower)                                                   |
| LLM (answer step)           | **Claude Opus 5.5** (`claude-opus-5-5`, $4 / $20 per M tokens) at effort `low`, JSON output                                              | Follows grounding/refusal rules well; cost is measurable from `usage`                                                                           | Claude Haiku 5.5 ($0.10 / $0.50): run it as a second row to show the cost/quality trade-off |
| LLM judge                   | **Claude Sonnet 5.5** or Haiku 5.5, plus a manual check of ~20%                                                                          | Correctness and citation support need judgement; hit-rate and MRR are computed exactly                                                          | RAGAS 0.4.x (faithfulness, context recall)                                                  |
| Optional extra              | **Contextual retrieval**: an LLM writes a 1–2 sentence context prefix per chunk                                                          | Anthropic reported top-20 retrieval failures falling from 5.7% to 2.9% with contextual embeddings + contextual BM25                             | Only if time allows                                                                         |
